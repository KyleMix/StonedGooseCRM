# Crew Onboarding

**Category:** HR / Crew
**Owner:** [Producer]
**Last reviewed:** REPLACE

## Purpose

When SG brings on a new freelance crew member, they end up in the
right systems on day one — Twenty, contracted, paid setup, gear-access
permission — so we don't reinvent the process every time.

## When to use

A new freelancer has been hired (or agreed in principle) to crew an
upcoming Job.

## Who's involved

- **Owns:** Producer
- **Supports:** Finance (W-9 / payment), Crew lead (gear orientation)

## Prerequisites

- Verbal or written agreement on day rate / project rate
- Job (or near-future Job) they're being hired for

## Step-by-step

1. **Create a Person in Twenty** with `contactType = Crew`. Fill in
   name, email, phone, city, role description.
2. **Send the crew engagement letter** using
   [`documenso-templates/crew-engagement.md`](../../documenso-templates/crew-engagement.md)
   via Documenso. Set the envelope's `externalId` to the related Job
   id so the Phase B webhook can track it.
3. **Collect tax info:**
   - For US: W-9
   - For non-US: W-8BEN
   - Store in [REPLACE — your secure document location]
4. **Add to payment system** — your accountant tool / direct deposit
   setup. Confirm SG can pay them via the agreed method.
5. **Brief them on SG workflow:**
   - How call sheets get sent (which channel, how far in advance)
   - Gear handling expectations
   - Data-wrangling expectations (link `post-shoot-data-wrangling.md` if
     they're doing it)
   - Invoice format and payment terms
6. **Add them to the next call sheet's distribution** so they're in
   the loop.

## Common mistakes to avoid

- Don't put a freelancer on a shoot before the engagement letter is
  signed.
- Don't pay a freelancer without their tax form on file.
- Don't share venue / client confidential info before signature.
