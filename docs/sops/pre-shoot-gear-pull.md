# Pre-Shoot Gear Pull

**Category:** Production
**Owner:** [Camera A / DP]
**Last reviewed:** REPLACE

## Purpose

Every shoot leaves the studio with the right kit, packed, charged,
and labeled — so the on-set crew never wastes time discovering a
missing cable.

## When to use

Once a Job moves to `In Prep` status. Triggered by Twenty workflow #4
(auto-creates a "Pull gear list and confirm rentals" task 14 days out
from `job.date`).

## Who's involved

- **Owns:** Camera A / DP
- **Supports:** Audio (audio gear pull), Producer (rentals)
- **Informs:** Crew on the call sheet

## Prerequisites

- Job is in `In Prep` status
- Run-of-show draft exists on the Job record
- Package (`job.package`) is set so you know what's being delivered

## Step-by-step

1. **Open the Job in Twenty.** Read the run-of-show and the package
   inclusions so you know how many cameras, mics, and lights to plan
   for.
2. **Pull the gear list** for the package type:
   - Single-cam comedy: 1 body + 24-70 + 70-200 + 2 batteries + 2 SD cards
   - 3-cam multi-cam: as above × 3, plus matched lens kits, plus tally
   - Promo / brand video: add B-roll body, slider, gimbal, LED panels
   - Wedding: add silent shutter body, add prime kit
   - [REPLACE — add your real package gear lists]
3. **Audio pull:**
   - Lavs (count = number of performers on mic) + spares
   - Board feed cable + DI box
   - Recorder + SD cards + backup batteries
   - Headphone splitter for monitor
4. **Charge everything.** Camera batts, audio batts, lav transmitters.
   Confirm SD cards are formatted.
5. **Confirm any rentals.** Open the rental Quote (if one exists) and
   email the vendor to confirm pickup time. Pickup is the day before
   the shoot.
6. **Label the cases** with a piece of gaff tape: `SG / Job name / date`.
7. **Update the gear-pull task** in Twenty: status `Done`, paste the
   final gear list as a comment on the Job.

## Common mistakes to avoid

- Don't assume the previous shoot's pack list applies. Each Job's
  run-of-show is the source of truth.
- Don't forget backup batteries for lav transmitters — they die first.
- Don't pull gear without checking the rental confirmation —
  double-booking with a rental house is a real risk.
